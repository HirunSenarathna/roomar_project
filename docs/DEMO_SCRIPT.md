# 3-Minute RoomAR Demonstration Script

## 0:00–0:20 — Problem and solution

“RoomAR is a browser-based augmented-reality interior design prototype. It helps a user preview furniture and curtains in their real room before making a purchase or design decision. It provides both marker-based catalogue preview and markerless spatial placement.”

## 0:20–0:45 — Marker-based AR

- Open Marker Preview.
- Show the Hiro marker.
- Let the sofa appear.
- Switch to the chair or curtain.

Say: “This mode uses a known marker to anchor the selected 3D product. The product stays registered to the marker as I move the camera.”

## 0:45–1:40 — Markerless furniture placement

- Open Room Mode and enter AR.
- Move the phone across the floor.
- Point out the green reticle.
- Place a sofa.
- Place a table/chair.
- Rotate and recolour the selected object.
- Use Move and relocate it.

Say: “The markerless mode uses WebXR hit testing. Furniture is accepted only on approximately horizontal surfaces, and the reticle gives the user placement feedback before committing.”

## 1:40–2:05 — Advanced interaction and collision

- Attempt to place or move an object into another object.
- Show the collision warning.
- Move it to a valid position.

Say: “The advanced interaction is a multi-step object manipulation workflow with placement, selection, movement, rotation, resizing, colour customization and bounding-box collision validation.”

## 2:05–2:40 — Curtain mode

- Select Curtains.
- Aim at a textured wall.
- Place the curtain.
- Make it wider/taller.
- Change colour.
- Open and close it.

Say: “Curtains use vertical-surface placement. Their width and height can be changed independently, and the two curtain panels animate open and closed without expensive cloth simulation.”

## 2:40–3:00 — UX/testing close

- Show help/status feedback briefly.
- Clear room or show the final layout.

Say: “The interface provides scanning, placement, tracking and error feedback. I tested the build across different floor/wall textures and lighting conditions, and optimized the included GLB models for browser delivery.”
